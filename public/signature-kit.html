Welcome Wings · Brand System

Email Signature Kit

One signature system, two tiers. Everything is built to paste cleanly into Gmail and render the same way for whoever receives it. Each block flexes around how much information a person has — so an individual signature and a team signature still read as one family.

The System

Four zones, always in the same order

Every signature stacks the same way. A zone simply appears or disappears depending on what the person has — the type, color, and spacing never change.

Structure

1 · Identity — name, then role line
2 · Contact — email (if any) and phone
3 · Channels — WhatsApp, when used
4 · Anchor — website, always last

Type

Georgiadisplay — names, taglines
Arialbody — roles, contact

Color

#14233f · navy — names, links
#5b6472 · slate — roles
#3a4150 · ink — contact text

Setup

Installing a signature in Gmail

  1. Open this file in a browser. Click inside the white box for the right person.
  2. Select all (Cmd/Ctrl + A), then copy (Cmd/Ctrl + C).
  3. In Gmail: gear icon → See all settings → General → Signature → + Create new.
  4. Click into the signature box and paste (Cmd/Ctrl + V). Delete any stray -- Gmail adds at the top.
  5. Scroll to the bottom and Save Changes. Send yourself a test to confirm.
If it looks too big after pasting: Gmail applies its own base text size to pasted content. In the compose/signature toolbar, set the text-size to Normal (the T▾ size button), or check Settings → General → Default text style isn't set to Large. The sizes here are already tuned compact.
Individual-tier logo step: the logo here is embedded for preview only and won't survive the paste. After pasting, click where the logo belongs, hit the image icon in the signature toolbar, upload the high-res PNG, and size it to Small/Medium. That keeps it sharp for every recipient.
Maintenance

Adding someone new

Three questions decide which tier and which rows they get:

Do they have their own title? Yes → Individual tier, use their real title. No → Team tier, role line reads "Guest Services."
Do they have an email to publish? Yes → include it before the phone. No → the contact line starts with the phone.
Do they take WhatsApp? Yes → add the WhatsApp row beneath the contact line. No → skip it; nothing else moves.
Phone numbers are always formatted +1 (XXX) XXX-XXXX. Website always anchors the bottom. Keep names consistent — decide once whether the team uses first names or full names, and apply it across everyone.
